## Current UI observations

Strengths:
- Mountain concept is already visible.
- Base Camp language is clear.
- Today's Climb exists.
- User goal and time budget are visible.
- Camps create a sense of vertical journey.

Problems relative to the new product vision:
1. The UI still describes IELTS Optimizer V2 as a separate mode.
2. Progress is presented as lesson completion (1/5, 20%) rather than competency mastery.
3. Camp unlock language is still course-like.
4. Band ranges are shown as if the journey were a simple linear band ladder.
5. Current copy focuses on lesson content rather than evidence-backed current learner state.
6. The mountain is currently more of a course map than a true adaptive expedition.
7. Today's Climb is present, but the reason for today's climb is not yet evidence-rich enough.
8. Streak is visible, but verified learning progress is not equally prominent.
9. The UI should eventually explain what the learner can now DO, not only what lesson they completed.
10. Lesson 2 being "coming soon" is acceptable for V0.1 but should disappear once the competency-driven lesson engine exists.

## Desired future direction

One mountain.
No permanent mode switch.
Mountain progression derived from:
- competency mastery
- retention
- transfer
- route readiness

Today's Climb should be generated by the adaptive planner and should explain why it was selected.
