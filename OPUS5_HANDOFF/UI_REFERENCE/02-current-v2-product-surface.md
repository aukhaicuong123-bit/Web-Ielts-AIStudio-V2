   "fix one bottleneck today"

   the learner should not manually select a random lesson.

3. Practice already connects tasks to:
   subskills
   evidence
   errors

4. Progress already has a verification mindset:
   "Did the intervention actually fix my weakness?"

5. Profile already separates:
   learner configuration
   evidence/assessment state

6. ZeroClimber already provides:
   mountain metaphor
   route
   camps
   Today's Climb
   learner goal
   daily budget

These are strong foundations for the unified system.

# CURRENT PRODUCT PROBLEMS EXPOSED BY THE UI

1. V2 and ZeroClimber still feel like separate surfaces.

2. ZeroClimber currently describes progression largely through:
   lesson completion
   camp unlocks
   percentage

3. Current mastery visualization is mostly subskill-based, while ZeroClimber needs a unified competency graph.

4. The current mountain is still closer to a course map than a truly adaptive expedition.

5. Today's Climb exists, but its "why" is not yet fully driven by evidence in the ZeroClimber experience.

6. The current UI still uses "mode switching" language.

7. Base Camp is presented as:
   Band 0 ? 4.0
   while the long-term architecture should be competency-readiness based rather than a simplistic band ladder.

8. Streak and lesson completion are more visible than verified retention/transfer.

9. The UI currently tells users what lesson they completed more clearly than what new abilities they can independently perform.

10. Lesson 2 being "coming soon" is a V0.1 prototype placeholder, not a final curriculum strategy.

---

# FUTURE UX DIRECTION

The future Home / Mountain screen should answer:

1. Where am I?
2. What can I already do?
3. What is currently blocking me?
4. Why is today's climb important?
5. What is the next best action?
6. How close am I to my goal?

Future progression should derive from:

competency mastery
+
retention
+
transfer
+
route readiness

not simply:
lesson completion.

---

# GOLDEN UI PRINCIPLE

The mountain should show where the learner is.

The learning engine should decide where the learner goes next.

The evidence engine should determine whether the learner really climbed.
